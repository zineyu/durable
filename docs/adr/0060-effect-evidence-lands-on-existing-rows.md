# ADR 0060: 副作用证据落在现有领域行，落点表是唯一判定处

- 状态：已接受。细化 ADR 0037 的工具节点三态、ADR 0052 的工具调用身份与 ADR 0059 之后的类别表
- 日期：2026-11-04

## 背景

`#80` 要求领域内核按 `effects` 的策略表实现六类副作用，并把「证据落库」收敛成唯一入口。`#78` 已经把工具结局四态铺在 tool 节点上：节点先以已登记入树，下发前改写为已下发，再把结局或「结果未知」写回同一节点。界面、恢复与模型输入都按这些块读。

六类里工具四类天然落行。模型步骤与压缩不是：请求前不写任何行，流中只节流写 `run.progress`，成功后才把消息入树；失败与取消都不留消息。而引擎在 `#81` 与 `#82` 才接线，本条交付的是「库里能写出四态证据并被测试直接驱动」。

## 决策

**六类清单是 `EffectClass`**：`model_step`、`compaction`、`read_file`、`write_file`、`edit_file`、`bash`。前两个是网络调用，后四个各占一个 tool 节点。`const ALL` 是唯一清单，由一条测试钉住——新增一类时编译器不出声，这是全套里唯一靠测试守住的清单。

**不新增证据表。** 证据落在这四条现有领域行上：

| 类别 | 已登记 | 已下发 | 观测 | 丢失观测 |
| --- | --- | --- | --- | --- |
| 工具四类 | tool 节点入树 | 块改为已下发 | `Finished { outcome, duration_ms }` | `Unknown` |
| `model_step` | 不写行 | 不写行 | assistant 消息入树，同事务清空 `run.progress` | 不写行 |
| `compaction` | 不写行 | 不写行 | 压缩消息入树 | 不写行 |

模型步骤与压缩的「已登记 / 已下发」不写行，是因为它们的意图由消息 id 与进度表达（`#79` 的契约原文）。它们的观测就是消息入树，因此 `Ledger` 的观测带着内容块。

**唯一实现、唯一判定。** `impl Ledger for Store` 只有一个，`EffectIntent` 与 `EffectObservation` 各一个枚举，落点判定只有一处。`(类别, 观测)` 不匹配时返回 `StoreError::Invariant`，文案带类别名与观测变体名。错配因此是运行期发现，靠测试守住，而不是靠类型。

**幂等仍由 `ToolDefinition.idempotent` 表达。** 四个工具类的 `replay` 一律返回 `Replay::IfIdempotent`，类别表不复制「能不能重跑」这个事实（ADR 0052 已经把它放在工具定义上）。

**覆盖率是进程内状态。** `Store` 持有 `Coverage<EffectClass>`，读方法是 `Store::effects_declared()`。重启即清零，因此 `#83` 的矩阵必须在同一个进程里跑完才断言。

**过渡期保留四个旧方法。** `append_tool`、`set_tool_state`、`append_assistant`、`append_compaction` 仍是落点表调用的写入方法，引擎一行不改；`#81` 接线后删除它们。因此本条通过之后到 `#81` 落地之前，「唯一入口」是按实现说的，不是按接口说的：证据的落点判定只有一处，但这四个方法仍能被直接调用。

## 备选

- **新增一张证据表**：能表达一次动作的完整历史。代价是两份真相，恢复与界面要读哪一份立刻成为新问题，且 `#78` 刚铺好的四态白铺。
- **六类各自的意图与观测类型**（一个泛型 impl 加每类的关联类型）：错配在编译期不可能。代价是落点表被切成六处，「唯一入口」要跳六个文件才读得出来。
- **只做工具四类**，模型与压缩只填表态、落点留空：`#82` 要回头改落点表的形状与测试。
- **类别表写死 `Redo` / `GiveUp`**，`idempotent` 改为从类别表推导：类别表成为唯一来源，但幂等从工具的性质变成类别的性质，同一类别的两个工具不能再不同。

## 后果

- `#82` 只需把调用点接到同一张落点表；`#81` 只需删掉四个旧方法并改用许可证。
- `durable` 新增对 `effects` 的依赖，`deps.allow` 补一行 `durable effects`。
- 术语表补六个词：副作用类别、证据强度、许可证、意图、观测、覆盖率。
- 覆盖率不落库，因此「重启后仍能报出缺口」不在本条的能力范围内。
