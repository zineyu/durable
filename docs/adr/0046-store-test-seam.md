# ADR 0046: 第三条测试 seam：`Store`

- 状态：已接受。补充 ADR 0007 的 seam 清单
- 日期：2026-10-26

## 背景

ADR 0007 定义了两条 seam：`agent` 的 HTTP API 与 client 纯 reducer。ADR 0025 增加浏览器端到端 seam，说明 seam 清单不是封闭集合。

`crates/core` 承载 ADR 0012 的全部不变量：单一写入线、changeset 原子提交、提交成功后才广播、快照水位。这些不变量此前只由 `crates/agent/tests/*` 间接验证。那条路径要经过 HTTP 处理、进程启动、临时 workspace、临时 SQLite、脚本化 provider 与 SSE。内核的一处错误要跨过三层才可见，断言失败时无法区分错误属于内核、协议还是进程。

两类行为在端到端测试里无法稳定复现：同一个 `Store` 上并发写命令的读-改-写顺序取决于调度；「事务失败不广播」需要在提交点同时观察事件表与进程内事件总线。

## 决策

新增 **Seam 5：`Store`（内核）**。标题中的「第三条」指它为 ADR 0007 的两条 seam 补上第三条同层 seam；清单编号顺延为 Seam 5（Seam 3 由多节点规格定义，Seam 4 由 ADR 0025 定义）。

**形态**：用临时 SQLite 打开真实 `Store`，经公开写命令与读方法驱动，断言提交后的快照、事件序列与错误变体。不引入 mock，不直接执行 SQL，不新增只为测试存在的生产 API，不暴露错误码构造器；每个错误都经真实命令触发。

**归属**：用例位于 `crates/core/tests/`，按被测对象分文件。`command.rs` 保留写命令入口与事件信封的既有用例；新增文件按对象划分：写入线、事件序列与水位、队列与 run、分支命令、插话布局、读路径。

**责任边界**：

- 本 seam 回答「内核自己的对外行为是什么」：快照字段、事件顺序、提交与广播的关系、队列长度与 `busy`、错误变体。
- 协议形状、SSE 帧、进程生命周期与工具执行仍归 Seam 1。
- `hub` 的合并协议与总线仍归 Seam 3；浏览器渲染与断线重连仍归 Seam 4。
- 本 seam 不断言私有内部结构，不断言时间戳的具体数值。

## 端到端测试不能替代它的理由

- **失败距离**：端到端测试的失败点在 HTTP 或 SSE，原因可能在引擎、内核或进程。本 seam 的失败点就在被测命令上。
- **并发串行**：经 HTTP 提交时，并发写命令的顺序不可控。直接驱动 `Store` 才能在提交后断言链形状、队列顺序与事件条数。
- **事务失败不广播**：需要在提交点同时观察 `events_after` 与进程内事件总线。HTTP seam 只能看到事件流，看不到「事件表没有新增行」。
- **错误变体**：同一个错误经 agent 映射成协议码。本 seam 直接断言 `StoreError` 变体，为两层映射提供依据。
- **运行成本**：本 seam 不启动进程、不起 HTTP 服务、不跑 provider，用例在秒级完成。

## 代价

- **内核行为多一处契约**。`Store` 的公开写命令与读方法被两处测试引用：本 seam 与 agent seam。改变公开行为时必须同时更新两处。
- **夹具按目标重复编译**。每个集成测试目标是独立 crate，`tests/support/` 的夹具随每个目标各编译一次；规模预算也按目标计算。
- **不覆盖接线**。本 seam 不经过 HTTP 与 SSE，因此不能证明服务端把内核行为送到客户端。这条由 Seam 1、Seam 3 与 Seam 4 负责。
- **SQLite 是唯一存储实现**。本 seam 不构成存储适配器的 seam：测试使用真实 SQLite，不替换它。

## 备选

- **只保留端到端 seam**：写入线与并发串行的断言继续依赖调度与日志推断。
- **引入内存存储适配器**：本项目只有一个存储实现，多出的适配器只服务于测试，不构成 seam。
- **在 `Store` 上暴露错误构造器或测试钩子**：生产 API 为测试让路，且错误不再经真实路径产生。
- **让端到端测试直接执行 SQL**：断言越过公开边界，内核行为与存储实现被绑死。

## 后果

- 内核不变量的失败在一步之内可见，定位不依赖 SSE 日志。
- 「事务失败不广播」成为直接断言，不再靠推理。
- `Store` 的错误变体被直接覆盖，agent 与 hub 的映射有依据。
- 端到端测试收缩为协议、事件流、进程生命周期与工具执行；与新用例完全重复的内核断言已删除。
- 新增测试按被测对象分文件，遵守单文件 600 行的规模预算。
